# Quizlet import — 67 terms

Suggested title: Grammar Studio — Topics 1–2

Language: English for terms and definitions.

1. Open quizlet-all-terms.tsv in a text editor and copy all its contents.
2. In Quizlet, create a study set and choose Import.
3. Paste the text. Select Tab between term and definition, and New line between cards.
4. Check that the preview shows 67 cards, then create the set.
5. Copy the published set URL. In Grammar Studio → Flashcards → Open a Quizlet set, paste the URL and open it.

The file has no header row. It contains 40 Topic 1 and 27 Topic 2 glossary terms. Definitions include examples or usage notes. Topic 3 has not yet been released.

The site’s own flashcards work offline. An external Quizlet embed requires internet; no Quizlet set is created automatically by this export.
