# Grammar Studio

University grammar library: https://alyonazerg.github.io/grammarhub/library.html

## Topics

1. Parts of Speech, The Noun and The Article — 9 modules, articles organised by noun classes and special constructions.
2. The Pronoun and The Numeral — four 90-minute classes, relative clauses and mathematical English included.
3. The Adjective and The Adverb — planned outline, In development.

## Learning features

- Warm-up → Discover → Rule → Practise → Workshop → Use → Review → Homework.
- 82 theory blocks with immediate mini-controlled checks;45 warm-up questions.
- 2 controlled,2 freer and2 free activity sets per module. This is a selectable bank, not a requirement to complete all tasks within90 minutes.
- 104 main practice questions retained; written and speaking production plus homework.
- Board mode requests fullscreen, divides material into logical slides and supports arrows and stage transitions. Normal mode is restored on exit.
- Key terms are bold/highlighted; discussed word forms are italicised.
- 67 terminology flashcards with definitions and examples, topic filters and device-local review marks.
- Quizlet copy/export and optional explicit loading of an existing published set URL. No external Quizlet set is created automatically.

## Offline and exports

Download offline.html for the complete standalone course, including styles, code and favicon. No secondary requests are made unless the user explicitly opens an external Quizlet set.

Quizlet import: exports/quizlet-all-terms.tsv (Tab between fields;New line between cards). Instructions: exports/QUIZLET-IMPORT.md.

Implemented Topic2 coverage map for comparison with Kaushanskaya: exports/topic2-coverage.md.

Progress and drafts remain in the current browser. Export written answers to preserve them. Review marks are self-assessment, not certification.

## Sources

Kaushanskaya is the examination terminology reference. Universal/detaching are mapped to its defining group. Topic1 adapts grammar content from four supplied presentations, with slide references and corrected overgeneralisations. Additional grammar references: How English Works, Practical English Usage, Downing and A Student’s Introduction to English Grammar. TKT informs sequencing/assessment. The Good Grammar Book is excluded. Administrative presentation material is not included.
