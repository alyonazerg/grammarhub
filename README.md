# Grammar Studio

Four 90-minute university classes on English pronouns and numerals. English interface, guided discovery, theory, 32 practice questions with explanations, a 20-term glossary, production tasks, homework and a 60-mark open-book assessment.

## Open the course

The main index.html is self-contained: no external libraries, fonts or network requests. Download offline.html and open it in a current browser for classroom use without internet. Use Board mode for larger text and Print for the current view.

Progress and assessment drafts stay in the current browser. Export responses to preserve them. Reviewed means participation, not mastery.

## Publish

## Sources

Kaushanskaya is the examination terminology reference; universal/detaching are mapped explicitly to its defining-pronoun group. Supplementary references: How English Works, Practical English Usage, Downing and A Student’s Introduction to English Grammar. TKT informs sequencing and assessment. The Good Grammar Book is excluded. Practice examples are original.

Designed for B1+/B2 consolidation. Production and final assessment require teacher feedback. Syntax, schema and mark totals checked; browser visual QA was blocked by environment restrictions.
